# Tobii Glasses X application API
Welcome to the Tobii Glasses X application API.

This repository helps you explore and use the Glasses X application API. The API lets an external client connect to the application over WebSocket, stream video over WebRTC, control recordings, read device state, and receive real-time updates.

Use the Python examples in this repository to get started quickly. Each example shows how to connect to the API, send requests, and handle responses. The examples follow a simple pattern, so you can reuse the code in your own workflows or integrations.

The API is built on three core concepts: actions, properties, and signals. Actions trigger operations, properties expose the current state, and signals provide updates and streamed data.
Start with the connection example, then explore how to read data, control recordings, and subscribe to signals.
